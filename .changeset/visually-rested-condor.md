Backspace is now spelled `Backspace` in the command palette and the list of commands; a key binding may write `Backspace` or, as before, `BS`. Keys with several modifiers are shown as `Ctrl`, `Alt`, `Shift`, in that order, so `Shift+Alt+Z` now reads `Alt+Shift+Z`; a binding may still write them in any order.
