New run_file (X) and run_command (Shift+X) commands open a dialog for a command line to run without a shell, starting from the cursor item's path or empty, and accepting the same placeholders as [commands], such as {marked_paths}. Enter on an executable file now opens this dialog instead of the text preview, and on Windows a file inside an archive counts as executable by its extension, as on disk.
