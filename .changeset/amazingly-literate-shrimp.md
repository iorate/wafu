Eight commands and one setting have new names. Key bindings and settings under the old names are reported as unknown and ignored. The popup of `new_dir` is now titled `New directory`.

| Old name | New name |
|---|---|
| `mkdir` | `new_dir` |
| `next_mark` | `mark_next` |
| `prev_mark` | `mark_prev` |
| `page_up` | `cursor_page_up` |
| `page_down` | `cursor_page_down` |
| `run_command` | `run_command_line` |
| `pane_shrink_left` | `split_left` |
| `pane_grow_left` | `split_right` |
| `mkdir_enters_dir` (setting) | `new_dir_enters_dir` |
